# Fandom Crazy OS

A cozy retro desktop OS that themes itself around any fandom.

Download the latest version from [Releases](https://github.com/Lunaroxo/fandom-crazy-os/releases/latest):

- **Windows:** `Fandom.Crazy.OS.Setup.exe`
- **Linux:** the Linux zip, then run `bash setup.sh`
- **Android:** `Fandom-Crazy-OS.apk`
- **Mac:** the Mac zip

Once installed, the app checks for updates by itself every time it starts.
